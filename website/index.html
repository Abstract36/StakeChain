What's actually here

Three working pieces, all in one repository.

01

Yields aggregator

Live APY and TVL for Base staking, LST and lending pools, refreshed every 5 minutes, with junk-farm filters built in.

02

Agent-native API

An MCP server turns the data into tools any AI agent can call. Machine requests pay $0.001 per call in USDC via the x402 protocol — live today, self-hosted settlement, no accounts or API keys. Revenue flows to STACH stakers through an on-chain merkle distributor.

03

STACH staking

The original 2022 staking token, security-audited and hardened in 2026: flexible and 1–6 month locked pools, rewards backed by a real on-chain reserve. Live on Base Sepolia today.

The honest part

This is an experiment, not "the future of finance". The revenue model is machine consumers paying fractions of a cent per API call, settled on-chain — the paid tier is live; the dashboard and human endpoints stay free. The 2022 contract shipped with two critical bugs — the 2026 audit that found and fixed them is public. Read the code before trusting it with anything. Rates shown are market data, not recommendations. Nothing on this page is financial advice.

Wallet risk flags are accurate. Day one by the numbers: liquidity is tiny and not locked yet, the price is as unstable as a shallow pool implies, and the treasury still holds most of the fixed 42M supply. Wallets like MetaMask flag exactly that — they should. The flags fade as staking distributes the reserve and liquidity deepens; until then, treat STACH as what it is: an experiment.
