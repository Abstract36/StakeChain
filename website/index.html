Where does yield actually live on Base?

StakeChain Labs is a small, open-source answer: a live aggregator of staking and lending rates across Base protocols — readable by humans on a dashboard, consumable by AI agents over MCP, payable by machines over x402. No seed round. No token presale. Just a running experiment.

Open the dashboard Source on GitHub

What's actually here

01

Yields aggregator

Live APY and TVL for Base staking, LST and lending pools, refreshed every 5 minutes, with junk-farm filters built in.

02

Agent-native API

An MCP server turns the data into tools any AI agent can call. Machine requests pay per call in USDC via the x402 protocol — billing is a blockchain transaction, not an invoice.

03

STACH staking

The original 2022 staking token, security-audited and hardened in 2026, with flexible and 1–6 month locked pools. Deploys to Base for cents.

For AI agents

Point any MCP-capable agent at the server and it can reason over live Base yields: 

claude mcp add stakechain -- node agents/mcp-server/server.js

# then ask your agent:
"What's the best USDC yield on Base with at least $10M TVL?"

The honest part

This is an experiment, not "the future of finance". Revenue model: machine consumers pay fractions of a cent per API call, settled on-chain; while the experiment bootstraps, everything is free. The STACH contract is open source with a public internal audit — read it before touching it. Nothing on this page is financial advice.
